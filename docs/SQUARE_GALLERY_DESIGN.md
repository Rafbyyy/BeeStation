# Square game gallery

Design Read: a local-play game launcher for friends sharing a PC; full game artwork, a dark trailer stage and one honey-colored selection accent. ENERGY 3 / RHYTHM 1 / MOTION 2.

The selected square is the focal point. Neighboring games recede through smaller scale and lower opacity. The layout keeps equal page edges and a stable center while scrolling or dragging. Real game images are used; portrait artwork is cropped from the top to preserve its title rather than stretched. User-selected covers take priority. Missing artwork keeps the existing initials fallback.

Dark backing behind the header, collection label and add action protects contrast even on the brightest trailer frame. Keyboard focus uses a honey outline against an opaque dark band. These are readability treatments rather than extra decorative effects.

The supplied Shiny Button preview was observed directly in headless Chrome at the 21st.dev page and its own CDN preview. Its moving conic highlight informed a new CSS edge treatment using BeeStation's honey accent. No code, assets or button copy from the reference are copied. The highlight plays on selection and strengthens during the hold, without an endless animation. The UI remains the existing TypeScript/CSS application.

The existing 700 ms hold opens the session page. The selected square grows during the hold; release, movement, lost focus, scroll or cancellation restore its resting state and stop the hold sound. A separate confirmation tone marks a completed hold. Opening the page does not create a session or launch a game. Enter/Space support the same hold, and reduced motion removes enlargement and moving highlights while preserving feedback and timing.

Taste Skill informs proportion, real assets and restrained interactions. Its marketing-page recipes, no-carousel rule and palette dealers are superseded by the user's explicit existing-app carousel brief. UI/UX Pro Max informs immediate press feedback, transform-based animation, cancellation and keyboard operation. Anti-Slop runs during implementation; its delivery review is scoped to the modified gallery. REA's routing guidance leaves this complete source repository to normal coding tools; the external preview observation is ordinary Playwright evidence, not REA Evidence. No analysis engines or new runtime dependencies are installed.

The footer's source and height, native pointer, dot trail, trailer/audio controls, saved game defaults and personal player layouts are preserved. Tests use isolated FakePad data; screenshots of fixtures are labeled SIMULASI.
